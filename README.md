# APEX Kart Club · Evergreen Park

직접 제작한 저폴리곤 숲 서킷에서 즐기는 3D 아케이드 카트 레이싱 프로토타입입니다. 참고 이미지에서는 후방 추적 카메라와 HUD 배치만 참고했습니다. 캐릭터, 차량, 환경, 로고, UI, 이펙트와 소리는 자체 제작했습니다.

## 온라인 플레이 및 배포

- 게임: [apex-evergreen-kart.netlify.app](https://apex-evergreen-kart.netlify.app/)
- 소스: [reiner5427-eng/kart-racing](https://github.com/reiner5427-eng/kart-racing)
- 현재 프로덕션은 Netlify Drop으로 직접 배포했습니다. GitHub 자동 배포는 아직 연결되지 않았습니다.
- 다시 배포하려면 `node scripts/build.cjs`를 실행하고 `dist/` 폴더를 Netlify 프로젝트에 업로드합니다.
- 저장소 연결 후에는 `netlify.toml`의 빌드 명령과 배포 폴더(`dist`)를 사용할 수 있습니다.

## 실행

1. `index.html`을 Chrome 또는 Edge에서 엽니다. 파일을 더블클릭해서 실행할 수 있습니다.
2. **스피드전** 또는 **아이템전**을 선택합니다.
3. `3 → 2 → 1 → GO!` 이후 출발합니다.

설치, 빌드, 개발 서버, 인터넷 연결이 필요하지 않습니다. `index.html`, `style.css`, `game.js`, `vendor/`를 함께 보관하세요. WebGL을 지원하는 브라우저가 필요합니다. 오디오는 기본 OFF이며 화면 오른쪽 아래에서 켤 수 있습니다.

## 조작

| 키 | 동작 |
| --- | --- |
| W / ↑ | 가속 |
| S / ↓ | 브레이크, 정지 후 후진 |

작은 화면에는 터치 조작 버튼도 표시됩니다. 다른 창으로 이동하거나 화면이 숨겨지면 입력을 비우고 경기를 일시 정지합니다.

## 게임 모드

두 모드 모두 플레이어 1대와 AI 5대가 **3랩**을 달립니다. 12개 체크포인트(피니시 포함)를 순서대로, 정방향으로 통과해야 랩이 인정됩니다. 순위는 검증된 체크포인트와 현재 구간의 진행도로 계산합니다. AI는 서로 다른 속도·가속·코너링·주행 라인을 가지며, 공격으로 체크포인트를 놓치면 이전 체크포인트로 복귀합니다.

- **스피드전:** 아이템 박스가 없습니다. 드리프트로 부스트 에너지를 채우면 부스터를 얻습니다. 최대 2개를 보유하며 Space로 1.8초 동안 사용합니다.
- **아이템전:** 트랙에 배치된 회전 큐브에서 아이템을 얻습니다. 슬롯은 2개이며 E/Ctrl로 먼저 얻은 아이템부터 사용합니다. 박스는 4초 뒤 재생성됩니다. AI도 아이템을 획득하고 사용합니다. 앞선 순위에서는 실드·부스터, 뒤쪽 순위에서는 로켓·물폭탄의 확률이 높습니다.

## 아이템 5종

| 아이템 | 효과 |
| --- | --- |
| 추적 로켓 | 진행도상 가장 가까운 앞선 상대를 추적합니다. 명중하면 감속 및 짧은 제어 불가. 벽 또는 제한 시간에 제거됩니다. |
| 물폭탄 | 전방 9m에 떨어져 1.1초 뒤 반경 6.5m 안의 카트를 감속시킵니다. 자신도 맞을 수 있습니다. |
| 슬립 패드 | 뒤쪽에 보라색 패드를 설치합니다. 다른 카트가 밟으면 회전 및 감속. 최대 16초 유지됩니다. |
| 실드 | 3초간 보호막을 표시하고 공격 1회를 방어합니다. |
| 부스터 | 즉시 2초 동안 가속합니다. |

## 운전 감각과 카메라

- 전진 속도와 횡방향 속도를 분리하고, 조향·관성·그립·마찰을 함께 계산합니다.
- 고속에서는 조향을 완화합니다. 드리프트 중에는 횡방향 그립이 낮아져 차체와 이동 방향에 차이가 납니다.
- 드리프트 충전 24 / 50 / 80부터 3단계 미니 터보가 제공됩니다. 연기·색상 파티클·타이어 자국으로 충전을 표현합니다.
- 잔디에서는 가속력과 최고속도가 낮아집니다. 트랙 외곽 충돌 경계에서는 속도가 줄고 튕겨 나옵니다.
- 기본 카메라는 카트 뒤 7.5m, 위 3.8m입니다. 상대 위치와 시선을 부드럽게 보간하며, 속도·드리프트·부스트에 따라 거리와 FOV가 달라집니다.

## CONFIG 조절

`game.js` 맨 위의 `CONFIG`에서 조절합니다. 변경 후 새로고침하세요.

| 설정 | 조절 대상 |
| --- | --- |
| `vehicle.maxSpeed`, `acceleration`, `brakePower` | 주행 속도(m/s), 가속 및 브레이크 |
| `vehicle.steering`, `grip`, `drag` | 회전 감도, 일반 그립과 마찰 |
| `drift.grip`, `chargeRate`, `speedLoss` | 미끄러짐, 미니 터보 충전, 드리프트 속도 손실 |
| `drift.boostChargeRate` | 스피드전 부스터 충전 속도 |
| `boost.duration`, `multiplier`, `capacity` | 부스트 시간, 속도 배수, 보유량 |
| `camera.distance`, `height`, `fov`, `damping` | 카메라 거리·높이·시야·추적 보간 |
| `items.weights` | 순위별 아이템 가중치: 로켓 / 물폭탄 / 패드 / 실드 / 부스터 순서 |
| `items.respawn`, `shieldDuration` | 박스 재생성 및 실드 시간 |
| `effects.particles`, `skidMarks` | 파티클과 타이어 자국 최대 개수 |

코스는 `Track` 생성자의 `points` 배열로 변경할 수 있습니다. 트랙 폭과 체크포인트 수는 생성 시 계산됩니다. 6대·3랩·2칸을 바꾸면 HTML의 해당 HUD 숫자/슬롯도 함께 변경해야 합니다.

## 구조와 검증

- `index.html`: HUD, 메인 메뉴, 일시 정지, 결과 화면
- `style.css`: 자체 CSS UI와 반응형 레이아웃
- `game.js`: Game, Track, Vehicle, RaceManager, ItemManager, InputManager, UIManager, Effects, AudioEngine
- `vendor/three.min.js`: Three.js 0.160.1 일반 스크립트. 라이선스는 `vendor/THREE-LICENSE.txt` 참조

Chrome의 `file://`에서 실제 렌더링과 키 입력을 확인했습니다. 가속·브레이크·후진, 드리프트의 이동 방향 차이, 미니 터보, 부스터, 체크포인트 건너뛰기 방지, 아이템 획득/재생성, 아이템 5종, 두 모드의 3랩 전체 시뮬레이션, 결과 화면·재시작·메뉴 복귀, 일시 정지·포커스 이탈 입력 해제, 화면 크기 변경을 검증했습니다.

60fps를 목표로 환경 오브젝트를 인스턴싱하고 파티클과 타이어 자국은 고정 풀을 사용합니다. 실제 프레임 속도는 GPU와 해상도에 따라 달라집니다. 아케이드 프로토타입이므로 트랙 외곽은 연속 충돌 경계로 처리하며 개별 나무·바위마다 정밀 물리 충돌을 계산하지 않습니다.
